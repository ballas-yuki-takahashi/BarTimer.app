# Bar Timer 1.2
Macのメニューバーに横バーと残り時間を表示するタイマー。必要なときは最前面の小窓も表示できます。macOS 12以降、Apple Silicon / Intel対応のソースコードとビルド用スクリプトです。外部サービス・通信・追加パッケージは使いません。

## 初回起動
1. ZIPを展開。
2. `Build.command` を実行（ダブルクリック）。Apple Command Line Toolsがなければインストールの案内が出ます。インストール後に再実行してください。
3. 同じフォルダに `Bar Timer.app` が生成され、メニューバーに横バー＋残り時間が現れます。クリックし「時間・終了時刻を設定…」から設定します。次回からアプリを直接開けます。アプリはApplicationsフォルダへ移動可能です。

ダウンロードしたcommandファイルの実行がmacOSにブロックされた場合は、内容を確認したうえで、ターミナルに `bash ` と入力し、Build.commandをドラッグしてEnterで実行できます。macOSの全体的なセキュリティ設定を無効にする必要はありません。

## 使い方
- 起動すると細い小窓（残り時間とバーのみ）とメニューバー表示が出ます。作業中のアプリのフォーカスは奪いません。設定欄つきの大きい窓はメニューの「時間・終了時刻を設定…」か右上の矢印で開きます。横バーは約45pt、残り時間は分:秒で表示します。
- メニューバーが混んでいる、またはノッチ（カメラ部分）の裏に隠れて見えないときは、アプリをもう一度開くと小窓が表示されます。
- 二重起動はしません。起動中にもう一度開くと、起動中のアプリの小窓を表示します。
- メニューの「時間・終了時刻を設定…」で小窓を開きます。閉じてもメニューバーで計測は継続。
- 「時間で指定」と「終了時刻で指定」を切り替え可能。
- 終了時刻は24時間表記で、例：14 : 30 → 「今日 14:30 まで」。現在時刻を過ぎている場合（同じ時刻も含む）は翌日として表示します。スタート時に終了日時を確定します。Macの現地時刻を使います。
- 時刻指定の「停止」は計測解除です。一時停止によって予定時刻がずれることはありません。再スタートすると入力時刻の次の到来を対象にします。
- 時刻指定中の＋1分／＋5分は終了日時を延長し、画面の終了時刻も更新。終了後の延長は現在時刻から追加分を計測します。
- メニューバーのスペースが足りないと表示が隠れる場合があります。メニューバーを自動で隠す設定のときも常時表示にはなりません。
- 分・秒を入力して「スタート」。設定だけ反映する場合は「設定」。1秒〜5999分59秒。
- 5 / 10 / 15 / 25 / 45 / 60分のプリセット。
- 進行中は設定欄をロック。一時停止すると変更可能。「設定」は進捗をリセットします。
- ＋1分 / ＋5分は残り時間を延長。バーの最大値は必要に応じて拡張します。
- 一時停止 / 再開、リセット、右上の矢印で細い表示に切り替え。
- 終了すると赤いバーと超過時間を表示。音は一度だけ。スピーカーで音のオン・オフ。
- ウィンドウはタイトル部分をドラッグして移動。閉じても計測は続き、メニューバーのタイマーアイコンから再表示できます。終了も同メニューから。
- 通常のアプリより前面に表示し、各デスクトップにも表示する設定です。OSのシステム画面や一部のフルスクリーン環境では前面表示が制限される場合があります。
- スリープ中の時間も残り時間に含みます。スリープ中に音は鳴らず、復帰時に終了を判定します。
- 最後に設定した時間と音設定を保存。終了・再起動で進行中の計測は復元しません。

## 「ぽいっと」と連動
ぽいっと（やることを仕分けて見積もり、計測する Artifact）から、見積もり時間でタイマーを始められます。

- ぽいっと: https://claude.ai/artifact/NHLvusXoYdBanCFVbh2KHt
- GitHub の親 Issue のサブ Issue を見積もって取り込むときは、Claude Code に「ぽいっとに <Issue の URL> を入れて」（「ToDoに」「やることリストに」でも可）と頼みます。手順は `.claude/skills/poitto-import/SKILL.md`。

1. ぽいっとのタスクの行で Bar Timer アイコンを押す。Bar Timer がそのタスク名と見積もり時間でカウントダウンを始めます。
2. 作業時間は、一時停止中を除いて数えます。見積もりを超えた分も数えます。
3. 終わったら、次のどちらかで完了にします。
   - Bar Timer の「完了」（またはメニューの「タスクを完了して実績をコピー」）。一時停止を除いた実績がクリップボードに入るので、ぽいっとのページで ⌘V を押すと記録されます。
   - ぽいっとのページで「完了」（またはチェック）。「▶ 計る」からの経過時間が実績の欄に入り、`bartimer://finish?task=…` のコピーで Bar Timer も止まります。ページで一時停止した分は引かれますが、Bar Timer 側で止めた分は引かれません。あとから「コピー」→ ⌘V で、Bar Timer が数えた実績に入れ直せます。

ぽいっとはページの中で複数のタスクを並行して計れます。行の Bar Timer アイコンを押したタスクが Bar Timer に表示されます（Bar Timer に出せるのは1件。計測中の行で押すと切り替え、もう一度押すと外れます）。そのタスクの一時停止・再開・完了・計測をやめる・削除は `bartimer://pause|resume|finish|cancel?task=…` としてコピーされ、Bar Timer がそれに合わせます。

- ✕ ボタンはタスクの計測をやめます（実績はコピーしません）。
- 計測中に別のタスクの「▶ 計る」を押すと、前のタスクは記録せずに新しいタスクへ切り替わります。
- 通信はしません。受け取るのはリンクだけで、返すのはクリップボードだけです。
- 「▶ 計る」は `bartimer://start?…` のリンクをクリップボードにコピーします。Chrome でコピーされたときは、Bar Timer が気づいて自動で計測を始めます（メニュー「Chrome でコピーしたタスクを自動で計る」でオン・オフ）。Bar Timer が中身を読むのは、Chrome がコピー元のページを付けた新しいコピーだけで、リンク以外の内容は捨てます。初回に macOS がペーストの許可を聞いてきたら許可してください。
- 自動で始まらないとき（ほかのブラウザなど）は、メニュー「コピーしたタスクを計る」で始められます。

## 検証状況
作成環境がLinuxのため、macOSでのコンパイル・ウィンドウ表示・音・Spacesの実機検証は未実施です。Build.commandはコンパイル後に、開始・一時停止・再開・超過・延長・リセット・スリープ相当の時間差・当日/翌日の終了時刻・不正時刻に関するモデルのテストを実行し、成功時のみアプリを生成します。

## ファイル
- main.swift: AppKit / SwiftUI本体と計測モデルのテスト
- Build.command: Mac上のビルド・テスト・ローカル署名・起動
- Info.plist: アプリ設定
- AppIcon.icns: アプリアイコン（kaichu_dokei.png から作成）
- kaichu_dokei.png: アイコンの元画像
- .claude/skills/poitto-import/SKILL.md: GitHub Issue をぽいっとに取り込む Claude Code のスキル

## 旧版からの更新
旧アプリをメニューから終了し、今回のZIPを別フォルダに展開してBuild.commandを実行してください。同じフォルダに既存のアプリがあるとビルドは上書きせず停止します。
